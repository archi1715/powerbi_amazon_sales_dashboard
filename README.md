Power BI Dashboard Project: Amazon Product, Sales, and Regional Performance Analysis

This repository presents a Power BI project that analyzes Amazon product sales, regional performance, and product-level trends through an interactive dashboard.  
The report includes multi-level views such as overview analytics, product performance cards, detailed product insights, and tooltip-enabled drill-downs.



📊 Project Features

1. Overview Page  
📷 Dashboard Preview:  
![Overview]("amazon-ss/Screenshot%2025-06-2%155014.png")

KPIs Displayed:
- Total Sales (89,076K)
- Seller Count (19K)
- Sum of Amount (98,432K)

Interactive Filters:
- Order Status (Shipped, Pending, Cancelled, etc.)
- Product Category
- Time (Date Range)

Visuals:
- Sales by State and City
- Sales Trend by Date
- Status-based filters with dynamic values
- Clickable product preview section



2. Product Page  
📷 Product Preview: 
![Product](./Screenshots/Screenshot%202025-06-26%20155145.png)

Product-Level Insights:
- Interactive card view of all products
- On click/hover, shows:
  - Sale Amount
  - Units Sold
  - Sale Price
  - Review Count

Filter Options:
- Product Category Selector
- Dynamic Image & Metric Reveal



3. Product Detail Page  
📷 Detail View:
![Detail View](./Screenshots/Screenshot%202025-06-26%20155424.png)

Deep Dive Features:
- Large product image display
- Detailed KPIs:
  - Sale Amount
  - Units Sold
  - Return Count
  - Reviews
- Sales trend chart over selected date range
- Date slicer available for precise time filtering



4. Tooltip Page  
📷 Tooltip Preview:
![Tooltip](./Screenshots/Screenshot%202025-06-26%20155520.png)

Dynamic Tooltip View:
- Enabled on product hover
- Displays:
  - Sale Metrics
  - Units Sold Trend
  - Review & Price Snapshots
- Helps with instant drill-down insights without navigation



📁 File Included

- `'Amazon_Sales_Dashboard.pbix'` – Power BI report file (all pages and visuals)



🧑‍💻 How to Use

1. Clone or download this repository.
2. Open `Amazon_Sales_Dashboard.pbix` in Power BI Desktop.
3. Click **"Refresh"** to update or connect to your dataset.
4. Use slicers, tooltips, and visuals to explore various business insights.
